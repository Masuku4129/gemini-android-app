# Работа без Google AI Studio (свой сервер + Termux)

Приложение говорит на протоколе Gemini. Скрипт `tools/gemini_proxy.py` запускается
на этом же телефоне в Termux, принимает запросы приложения и пересылает их в любой
OpenAI-совместимый сервис (OpenRouter, Groq, Cerebras, Mistral, GitHub Models,
локальный Ollama). Файлы, команды, правки, картинки на входе и стриминг работают как раньше.

## Установка (один раз)
```
pkg install python git
git clone https://github.com/Masuku4129/gemini-android-app
cd gemini-android-app
git checkout claude/custom-backend
```

## Запуск (каждый раз, пока пользуешься приложением)
```
termux-wake-lock
python tools/gemini_proxy.py
```
По умолчанию это OpenRouter и только бесплатные модели с поддержкой инструментов.
Другой сервис:
```
python tools/gemini_proxy.py --upstream https://api.groq.com/openai/v1 --all-models
```
Одна конкретная модель: `--model <id модели у провайдера>`.

## В приложении (экран входа)
- API key: ключ сервиса (OpenRouter и т. п.). Он хранится только в приложении и идёт на 127.0.0.1.
- Server address: `http://127.0.0.1:8787`
- Модель `0-auto` сама переключается на другую, если выбранная упёрлась в лимит или недоступна.

## Что не работает и о чём помнить
- Генерация картинок (Imagen / Nano Banana) через прокси недоступна.
- Бесплатные модели слабее Gemini и чаще ошибаются в правках. Подтверждение команд и правок
  в приложении лучше оставить включённым.
- Каждый шаг с инструментом - отдельный запрос к провайдеру, поэтому дневной лимит запросов
  у бесплатных тарифов расходуется быстро. Лимиты у провайдеров разные и меняются; проверяй их
  на сайте сервиса. Если один провайдер кончился, запусти прокси с другим `--upstream`.
- Ключ не вставляй в чаты и не коммить в репозиторий.

## Проверка прокси
`python tests/test_gemini_proxy.py` (поднимает тестовый сервер, сеть и ключи не нужны).
